# hepatocytes experiment packets

## Primary recommendation: Additive-assisted hepatocyte attachment and function benchmark on a fixed base cryomix
- decision this answers: Should Atlas prioritize "Additive-assisted hepatocyte attachment and function benchmark on a fixed base cryomix" as the main head-to-head wedge benchmark?
- why this is worth running: Best current wedge, but still better treated as a proving ground than a committed entry point.
- core claim: Several hepatocyte papers imply that post-thaw attachment and function gains come from adjuncts added around a standard DMSO-centered mix rather than from new base CPA chemistry.
- proposed test: Run a fixed-backbone additive benchmark with Trehalose, Alginate, Fetal Bovine Serum, University of Wisconsin Solution on a DMSO-centered base mix, using post-thaw function as the primary readout.
- keep fixed: base CPA backbone, species, specimen format, assessment window, specimen handling, post-thaw evaluation rubric
- compare: base cryomix only | base cryomix + Trehalose | base cryomix + Alginate | base cryomix + Fetal Bovine Serum | base cryomix + University of Wisconsin Solution
- primary readouts: function, viability
- secondary readouts: yield, transplantation
- strongest supporting papers: Cryopreservation of primary human hepatocytes: the benefit of trehalose as an additional cryoprotective agent | A novel method of cryopreservation of rat and human hepatocytes by using encapsulation technique and possible use for cell transplantation | Serum-free cryopreservation of porcine hepatocytes | Comparison of University of Wisconsin and ET-Kyoto preservation solutions for the cryopreservation of primary human hepatocytes
- evidence read: supporting papers=6 | strong outcomes=6 | contradictions=0 | transplantation papers=4
- main watch-outs: 6 relevant papers still have unknown preservation family labels | 6 relevant papers still have sparse step structure | Benchmark still lacks balanced evidence from both vitrification and slow-freezing
- translational value: Useful if the goal is to justify a first hepatocytes wedge around post-thaw attachment, function, and standardization.

## Alternative: Promote hepatocyte function-heavy protocols to transplantation endpoints
- decision this answers: Would "Promote hepatocyte function-heavy protocols to transplantation endpoints" materially sharpen the wedge decision if tested next?
- why this is worth running: This remains one of the highest-signal next experiments in the current domain slice.
- core claim: Several hepatocyte protocols that look promising on attachment or in-vitro metabolic function will reorder once they are compared on engraftment or transplantation outcomes.
- proposed test: The hepatocyte slice labels function more often than transplantation. Converting the strongest in-vitro function protocols into a small engraftment benchmark is likely higher-signal than inventing a new chemistry path immediately.
- keep fixed: assessment window, specimen handling, post-thaw evaluation rubric

- primary readouts: transplantation, function
- secondary readouts: viability, yield, morphology

- translational value: Useful if the goal is to turn a plausible hepatocytes wedge into a more decision-ready one.

## Alternative: Scale-up benchmark for banked or bulk hepatocyte handling
- decision this answers: Would "Scale-up benchmark for banked or bulk hepatocyte handling" materially sharpen the wedge decision if tested next?
- why this is worth running: This remains one of the highest-signal next experiments in the current domain slice.
- core claim: Scale-up losses in hepatocyte banking may come from handling and thaw workflow variance rather than core cryomix choice alone.
- proposed test: The hepatocyte corpus includes banking, bulk, and large-scale titles, but those papers are scattered across sparse workflow descriptions. A scale-up benchmark focused on loading, storage, thaw, and handling variance would test whether operational workflow dominates the observed attachment losses.
- keep fixed: assessment window, specimen handling, post-thaw evaluation rubric
- compare: current handling workflow | workflow with staged loading/unloading controls
- primary readouts: post-thaw recovery, workflow reproducibility
- secondary readouts: viability, yield, handling loss
- strongest supporting papers: Cryopreserved human hepatocytes from cell bank: in vitro function and clinical application | Bulk Droplet Vitrification: An Approach to Improve Large-Scale Hepatocyte Cryopreservation Outcome | Large-scale cryopreservation of isolated dog hepatocytes | Bulk Droplet Vitrification for Primary Hepatocyte Preservation
- evidence read: supporting papers=4 | strong outcomes=4 | contradictions=0 | transplantation papers=1
- main watch-outs: 2 relevant papers still have unknown preservation family labels | 4 relevant papers still have sparse step structure
- translational value: Useful if the goal is to turn a plausible hepatocytes wedge into a more decision-ready one.
